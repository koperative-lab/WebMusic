`@webmusic/ui/controls` draws one value per control: a bang button, an on/off
toggle, a number box, a slider, a dial, a clickable message box, a menu, tabs,
a multislider and a routing matrix, with a preset grid, an interpolation pad
(nodes) and a mapping-mode overlay. Each mounts against a structural binding —
a `snapshot()`, one command and an optional `subscribe` — and imports no
domain or Kernel type, so the same control drives a Kernel object's interface
(`@webmusic/kernel/objects`), an application store or a framework state.

## Import

```ts
import {mountToggle, mountNumber, mountMenu} from '@webmusic/ui/controls';

const toggle = mountToggle(host, {
  snapshot: () => ({on: store.running}),
  setOn: (on) => store.setRunning(on),
  subscribe: (notify) => store.subscribe(notify),
});
const tempo = mountNumber(otherHost, {
  snapshot: () => ({value: store.bpm, min: 20, max: 300}),
  setValue: (value) => store.setBpm(value),
});
const wave = mountMenu(menuHost, {
  snapshot: () => ({items: ['sine', 'square', 'sawtooth', 'triangle'], index: store.wave}),
  select: (index) => store.setWave(index),
}, {label: 'Waveform', cardHost: componentWindow});
// At teardown, remove each view. The store keeps its application owner.
toggle.destroy(); tempo.destroy(); wave.destroy();
```

To show a Kernel object, read its interface with
`objectInterfaceOf(runtime.getModule(id))`, map `snapshot()` to the control's
state and send each command back as a message through `interact()`.

## Interaction and ownership

Every control re-reads its binding on mount, on each notification and on
`update()`; it keeps no second copy of the value. A command may return a
promise; a thrown or rejected command reaches `onError` and the control keeps
showing the binding's value.

| Control | Pointer | Keyboard |
| --- | --- | --- |
| Button, message | Click presses and flashes | Enter or Space |
| Toggle | Click flips | Enter or Space |
| Number | Drag up or down (Shift: finer); click to type | Arrow keys and Page Up/Down step; type, then Enter; Escape cancels |
| Slider | Press or drag along the track | Arrow keys, Page Up/Down, Home and End |
| Dial | Drag: up or right raises the value, down or left lowers it; a press alone changes nothing | Arrow keys, Page Up/Down, Home and End |
| Menu | Click opens the choices as a card over a scrim in `cardHost`, or steps to the next item without one | Arrow keys step; in the card, arrows move, Tab cycles, Escape closes |
| Tabs | Click a cell | Arrow keys choose and move |
| Multislider | Draw across the bars | Arrow Left/Right move between bars; Up/Down and Page Up/Down change one |
| Matrix | Click a cell to switch it | Arrow keys move between cells; Enter or Space switches |
| Preset grid | Click recalls a stored slot or stores into an empty one; Shift-click stores; Alt-click clears | Arrow keys move; Enter recalls; Shift+Enter stores; Delete clears |
| Nodes | Drag the cursor; with `moveNode`, Shift-drag a node | Arrow keys move the cursor (Shift: farther) |
| Mapping overlay | Click a target to learn its control | Enter learns; Delete removes the mapping |

A button or message box flashes for `flashMs` after a press, and
`handle.flash()` flashes it when its value arrives from elsewhere, as when a
patch sends it a bang. Re-mounting any control on the same host destroys the
previous one.

## Tooltips

`mountTooltips(document)` names the icon button the pointer rests on in a
small ink box beside the pointer, at once, in place of the platform's delayed
`title` tooltip. Only an element that shows no words is named — its `title`, or
a control's `aria-label`; text, cards and components get no box. It serves the
whole document — every component's icon buttons, including those inside open
shadow roots — so a page mounts it once. In help mode an element's
`aria-description` joins its name, whether or not it shows text.

```ts
import {mountTooltips} from '@webmusic/ui/controls';

const tooltips = mountTooltips(document);
helpButton.addEventListener('click', () => {
  tooltips.setHelp(!tooltips.help);
  helpButton.setAttribute('aria-pressed', String(tooltips.help));
});
// When the page no longer wants them:
tooltips.dispose();
```

An element's name is its `title`, or the `aria-label` of a control (button,
link, tab, slider and the like), and only when the element shows no letter or
digit: an icon, or a glyph such as `×`. Keyboard focus
shows the box under the focused control; a press hides it until the pointer
leaves; touch shows none. In help mode the box adds the element's
`aria-description`, so a described element explains itself on hover.

<details class="component-section">
<summary>API</summary>

Every `mount…(host, binding, options?)` accepts an `HTMLElement` or open
`ShadowRoot` and returns a handle with `element`, `update()` and `destroy()`.
`mountButton` and `mountMessage` return a handle that also has `flash()`.
Importing the entry needs no DOM.

**Bindings**

| Mount | Snapshot | Command |
| --- | --- | --- |
| `mountButton` | `ButtonState`: `active?`, `disabled?` | `press()` |
| `mountToggle` | `ToggleState`: `on`, `disabled?` | `setOn(on: boolean)` |
| `mountNumber` | `NumberState`: `value`, `min?`, `max?`, `step?`, `float?`, `disabled?` | `setValue(value: number)` |
| `mountSlider`, `mountDial` | `RangeState`: `value`, `min`, `max`, `step?`, `float?`, `disabled?` | `setValue(value: number)` |
| `mountMessage` | `MessageBoxState`: `text`, `disabled?` | `press()` |
| `mountMenu`, `mountTabs` | `ChoiceState`: `items`, `index`, `disabled?` | `select(index: number)` |
| `mountMultislider` | `MultisliderState`: `values`, `min`, `max`, `float?`, `disabled?` | `setValues(values: readonly number[])` |
| `mountMatrix` | `MatrixState`: `columns`, `rows`, `cells` (row-major, 1 is on), `disabled?` | `setCell(column, row, on)` |
| `mountPresetGrid` | `PresetGridState`: `count`, `stored` (slot numbers), `current`, `disabled?` | `recall(slot)`, `store(slot)`, optional `clear(slot)` |
| `mountNodes` | `NodesState`: `nodes` (`x`, `y`, `radius` on the unit square), `cursor`, `weights?`, `disabled?` | `setCursor(x, y)`, optional `moveNode(index, x, y)` |
| `mountMappingOverlay` | `MappingOverlayState`: `active`, `targets` (`id`, `label`, `element`, `mapped?`), `learning?` | `learn(id)`, `unmap(id)` |

`mountMappingOverlay(host, …)` takes an `HTMLElement` host that is positioned;
it outlines each target's element relative to the host while `active`, dashed
when unmapped, solid with its source text when mapped, inverted while learning.
It draws nothing while inactive.

Every binding may add `subscribe(notify)`, returning its unsubscribe function.
Values without `float` are whole numbers: number boxes, sliders, dials and
multisliders round what they send. `step` defaults to 1 for whole numbers and
0.01 for a float number box.

**Options**

| Member | Default | Contract |
| --- | --- | --- |
| `label` | per control (`'Bang'`, `'Toggle'`, `'Number'`…) | Accessible name. |
| `className`, `part` | — | Extra class and part token on the root. |
| `stylesheet` | `true` | Install `controlsStyle`; false leaves styling to the host. |
| `onError` | — | Receives command, snapshot and subscription failures. |
| `fill` | `false` | The control takes its host's whole width and height instead of its natural size: the cell, track, knob or grid stretches and a button's or toggle's glyph scales with it. The host must have a size of its own. |
| `flashMs` (button, message) | `120` | How long a press shows inverted. |
| `orientation` (slider) | `'horizontal'` | `'vertical'` draws an upright fader. `'auto'` follows the control's shape: upright while it is taller than it is wide, and again when its size changes; use it with `fill`. |
| `cardHost` (menu) | — | The component window the choice card covers. |

`formatControlNumber(value, float)` formats a value as the controls show it.

**Tooltips**

| Member | Contract |
| --- | --- |
| `mountTooltips(document?, {help?})` | Mounts the document's tooltips, or shares the ones already mounted, and returns a `TooltipHandle`. `document` defaults to the global one; `help` sets help mode. |
| `handle.help`, `handle.setHelp(on)` | Help mode, one per document and shared by every handle. While on, `<html>` carries `data-wm-help`. |
| `handle.dispose()` | Releases this handle; the last release removes the box, its stylesheet and its listeners, and turns help off. Repeated calls do nothing. |
| `tooltipContent(element, help?)` | The `{name, description}` a tooltip would show for an element, or `undefined`. |

While its box is shown, an element's `title` is lifted off it, so the
platform's own tooltip never follows, and put back when the box hides; a
title changed meanwhile is followed and the new one put back. An icon control
whose title was its only name carries it as `aria-label` meanwhile. The box is
`aria-hidden`: names and descriptions already reach assistive technology from
the element.

**Accessibility.** Buttons, toggles and matrix cells are native buttons with
`aria-pressed`; the number box is a `spinbutton`; sliders, dials and
multislider bars are `slider`s that speak their value; tabs are a `radiogroup`;
the menu card is a modal `dialog` with a `listbox`, returning focus to its
trigger. Groups use a roving tab stop.

</details>

<details class="component-section">
<summary>Styling</summary>

`controlsStyle` follows [Visual design](/uikit/#theme-with-css-custom-properties):
square cells one control height tall, a 1px line, pressed and selected cells
inverted, a 2px ink focus ring inside the control and 30% opacity when
disabled. The slider and dial are the kit's fader and knob, with their tokens.

| Token | Fallback | Role |
| --- | --- | --- |
| `--wm-control-height` | `--wm-control-size`, `2rem` | Cell and field height. |
| `--wm-control-border` | `--wm-border` | Cell and field lines. |
| `--wm-foreground`, `--wm-accent-foreground` | `#111`, `#fff` | Ink and inverted ink. |
| `--wm-surface`, `--wm-surface-muted` | `#fff`, `#f3f3f3` | Cell fill and hover fill. |
| `--wm-control-scrim` | `rgb(0 0 0 / 45%)` | The menu card's scrim. |
| `--wm-focus-ring` | `2px solid` ink | Focus outline. |
| `--wm-tooltip-background`, `--wm-tooltip-foreground` | `--wm-foreground`, `--wm-accent-foreground` | The tooltip's fill and text. |
| `--wm-tooltip-font`, `--wm-tooltip-max-width`, `--wm-tooltip-radius` | `--wm-font-mono`, `20rem`, `--wm-control-radius` | The name's font, the box's widest, its corners. |

Canonical classes are `.wui-control` plus one modifier class per control —
`.wui-control--button`, `.wui-control--toggle`, `.wui-control--number`,
`.wui-control--slider`, `.wui-control--dial`, `.wui-control--message`,
`.wui-control--menu`, `.wui-control--tabs`, `.wui-control--multislider` or
`.wui-control--matrix` — and `.wui-control__cell`, `.wui-control__field`,
`.wui-control__bar`, `.wui-control__readout`, `.wui-control__card` and
`.wui-control__scrim` inside. The tooltip is `[data-wm-tooltip]` (a `[data-help]`
box carries a description), with `[data-part="name"]` and
`[data-part="description"]` inside; `tooltipStyle` is its stylesheet. The root's part name is the
control's name. A control mounted with `fill` carries `data-fill="true"` on
its root.

</details>
