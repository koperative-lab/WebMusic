`mountPlaylist()` renders an edge-to-edge row of previous, play/pause and next icon buttons and a
seek rail over an ordered list of entries. It paints caller-owned `PlaylistState` and routes every transport or selection gesture
through a required structural `PlaylistBinding`; it never owns a player, queue, decoder, or file.

Use [transport](/uikit/transport-time/transport/) for one current item without a queue,
[timeline](/uikit/transport-time/timeline/) for labelled time regions, or
[minimap](/uikit/transport-time/minimap/) for overview-range navigation. Mount this presenter directly when entry identity, loading policy, and player commands live in your store.

## Import

```ts
import {mountPlaylist} from '@webmusic/ui/playlist';

const handle = mountPlaylist(host, {
  snapshot: () => store.playlist,
  toggle: () => player.toggle(),
  previous: () => player.previous(),
  next: () => player.next(),
  seek: (fraction) => player.seek(fraction),
  select: (id) => player.select(id),
});
```

## Entry identity and patching

`items` is the caller's ordered queue. Each item supplies a stable `id`, a label, optional
preformatted duration, optional active state, and optional `loading` or `error` status. The
presenter deliberately does not format duration or decide whether an errored entry may be
selected; those are domain policies implemented by the binding.

The row list is rebuilt only when item ids, labels, or order change. Active state, status, and
duration are patched onto existing rows so frequent progress notifications do not steal focus
or cancel an in-flight row click. Keep ids unique and stable if code uses `controls.item(id)`.
Empty or whitespace-only ids reject the snapshot through `onError`; the prior DOM remains.
A rebuilt row list restores focus to the same id when that entry remains present.

## Binding and command settlement

All five user commands are required and may return promises. The presenter calls the requested
command, then re-reads the authoritative snapshot after it fulfills; synchronous throws and
current-command rejections reach `onError`. Older settlement may refresh accepted state but
cannot report over a newer command. Settlement after replacement/destruction is ignored, and
error-callback faults are contained. Subscription notifications can repaint independently. See
the [shared presenter shape](/uikit/api/#the-shared-presenter-shape) for common ownership and
cleanup rules.

The presenter does not apply an optimistic queue transition. `toggle()`, `previous()`, `next()`,
`seek()`, and `select()` must update caller state—then notify, fulfill, or both—for the visible
state to change.

<details class="component-section">
<summary>API</summary>

`mountPlaylist(host, binding, options?)` accepts an `HTMLElement` or `ShadowRoot` and returns a
`PlaylistHandle`.

**State**

| Member | Kind | Description |
|---|---|---|
| `playing` | `boolean` | Strict `true` chooses the pause icon and name and presses the toggle; otherwise uses play. |
| `progress` | `number` | Current-entry position. Finite values clamp to `0…1`; non-finite values paint as `0`. |
| `disabled?` | `boolean` | Strict `true` disables transport controls and blocks every command, including row selection; the root exposes `aria-disabled`. |
| `items` | `readonly PlaylistItem[]` | Ordered entries. Absence at runtime is treated as an empty list. |
| `status?` | `StatusState` | Optional owner readiness from [Status](/uikit/layout-feedback/status/). Defaults to waiting for an empty list and ready otherwise; loading/waiting use accessible square animations. Existing entries remain available. |

`PlaylistItem` contains required `id` and `label`, optional preformatted `duration`, optional
`active`, and optional `status: 'loading' | 'error'`. Strict `active: true` sets
`aria-current`; status adds a styling data attribute. Loading replaces the duration with the
shared four-square indicator and a visually hidden description; failure shows `Unable to load`.
The row and keyboard focus remain stable across those transitions. The presenter never mutates
the item objects. Only loading the active entry marks the entire playlist busy; background
prefetch remains local to its row.

**Binding**

| Member | Kind | Description |
|---|---|---|
| `snapshot()` | `() => PlaylistState` | Required pull port, read on mount, notification, command fulfillment, and explicit update. A throw reaches `onError` and leaves the current DOM unchanged. |
| `toggle()` | `() => void \| Promise<void>` | Required play/pause intent from the central transport button. |
| `previous()` | `() => void \| Promise<void>` | Required previous-entry intent. |
| `next()` | `() => void \| Promise<void>` | Required next-entry intent. |
| `seek(value)` | `(number) => void \| Promise<void>` | Required current-entry seek intent; receives a normalized `0…1` fraction. |
| `select(id)` | `(string) => void \| Promise<void>` | Required entry-selection intent from click, Enter, or Space. |
| `subscribe?(notify)` | `(notify: () => void) => () => void` | Optional change subscription; its disposer is called by `destroy()` and on same-host remount. |

**Options**

| Member | Kind | Default | Description |
|---|---|---|---|
| `label` | `string` | `'Playlist'` | Accessible name of the ordered entry list. |
| `stylesheet` | `boolean` | `true` | Installs `playlistStyle` unless explicitly `false`. |
| `transport` | `boolean` | `true` | False hides the transport bar for selection-only companion use; row selection remains available. |
| `previousLabel` / `nextLabel` | `string` | `Previous` / `Next` | Accessible navigation names. |
| `playLabel` / `pauseLabel` | `string` | `Play` / `Pause` | Accessible toggle names selected by playback state. |
| `seekLabel` | `string` | `Seek` | Accessible range name. |
| `classNames` | `PlaylistClassNames` | `{}` | Adds classes for `root`, `bar`, `button`, `previous`, `play`, `next`, `seek`, `list`, `item`, `number`, `label`, and `duration`. |
| `parts` | `PlaylistParts` | `{}` | Adds part tokens for the same node roles, preserving canonical tokens. |
| `onError` | `(error: unknown) => void` | — | Receives snapshot, command, subscription, and cleanup failures. |

**Handle**

| Member | Kind | Description |
|---|---|---|
| `element` | `HTMLElement` | Presenter-owned `.wui-playlist` root. |
| `controls.previous` | `HTMLButtonElement` | Always-present previous button. |
| `controls.toggle` | `HTMLButtonElement` | Always-present play/pause button. |
| `controls.next` | `HTMLButtonElement` | Always-present next button. |
| `controls.seek` | `HTMLInputElement` | Always-present range with DOM values `0…1000`. |
| `controls.list` | `HTMLOListElement` | Always-present ordered list. |
| `controls.item(id)` | `(string) => HTMLLIElement \| undefined` | Returns the currently rendered row mapped to an entry id. |
| `update()` | `() => void` | Re-reads and patches state; becomes a no-op after destruction. |
| `destroy()` | `() => void` | Idempotently disposes the subscription and removes presenter DOM and any installed stylesheet. |

**Accessibility.** Previous, toggle, and next are native icon buttons named in `aria-label` and
`title`, with the icon hidden from assistive technology; the toggle name follows `playing` and
its `aria-pressed` state is `true` while playing. Seek is a native range labelled `Seek`, and all four transport
controls reflect `disabled` through the native attribute. The ordered list receives `label` as
its accessible name. Each row is a focusable `role="button"` with click, Enter, and Space
activation plus `aria-current` for the active item. Root `disabled` blocks row selection as
well as transport commands. Loading descriptions are visually hidden live feedback; failures
remain visible. Empty waiting queues hide the unused transport and list. The binding retains
per-item selection policy, and caller nodes outside the presenter root are never rewritten.

<details class="component-section">
<summary>Styling</summary>

Use the shared [surface and palette tokens](/uikit/#theme-with-css-custom-properties) for
background (including `transparent`), foreground, accent, outer border and corner radius.
Presenter-specific tokens below take precedence within their documented roles.

The installed stylesheet resolves presenter-specific playlist tokens through shared `--wm-*`
values and then literals. The root has no inset: the transport row runs edge to edge, one control
height tall, with a hairline under it, and scrolls sideways without a visible scrollbar on a
narrow host. Icon buttons are muted and unframed when idle, ink on a raised fill on hover,
inverted while pressed, and 30% opaque when disabled. Rows highlight with the raised fill on
hover; the current row is inverted ink. Numbers and durations use mono type. A disabled
playlist drops its rows to 30% opacity.

The `status` class/part hook reaches whole-list feedback; `itemStatus` adds classes or parts
to each `item-status` host. Shared [Status tokens](/uikit/layout-feedback/status/) and
reduced-motion behavior apply to both.

**Parts**

`parts` adds tokens alongside canonical tokens and removes duplicates. Each transport button also
carries its action modifier.

| Node | Canonical part | `parts` key |
|---|---|---|
| Root | `root` | `root` |
| Transport bar | `bar` | `bar` |
| Previous button | `button prev` | `button`, `previous` |
| Toggle button | `button play` | `button`, `play` |
| Next button | `button next` | `button`, `next` |
| Seek range | `seek` | `seek` |
| Ordered list | `list` | `list` |
| Entry row | `item` | `item` |
| Entry number | `number` | `number` |

With `stylesheet: false`, the presenter installs no style node; the caller must style these
classes and parts itself.
