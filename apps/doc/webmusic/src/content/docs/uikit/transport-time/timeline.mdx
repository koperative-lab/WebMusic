`mountTimeline()` renders a ruler over a lane of ranged regions and point markers, with optional
loop, selection, playhead, and seeking layers. It paints caller-owned `TimelineState`; the
presenter owns only its DOM and forwards seek and region-selection intent through a structural
`TimelineBinding`.

Use [transport](/uikit/transport-time/transport/) for playback controls,
[minimap](/uikit/transport-time/minimap/) for moving a viewport over a dense overview, or
[playlist](/uikit/transport-time/playlist/) for ordered entries. The
[`<score-view type="map">`](/score/element/view/score-view/#map) element
composes this presenter; mount it directly when the time domain and region model belong to your
own store.

## Import

```ts
import {mountTimeline} from '@webmusic/ui/timeline';

const handle = mountTimeline(host, {
  snapshot: () => store.timeline,
});
```

## Domain and geometry

`duration` defines the complete non-negative domain. `viewport` narrows the visible interval;
an absent, reversed, or empty viewport falls back to the full duration. Regions are clipped to
that interval, while a point marker is rendered only when its `start` lies inside it. Duplicate
or empty region and tick ids are ignored.

Supplying `ticks` gives the ruler domain-authored positions and labels. Omitting it generates a
numeric ruler from `majorStep`, or from a readable interval derived from the viewport. `loop`,
`selection`, and `playhead` are display state rather than a second editable model: the binding
must publish any changes it wants the presenter to retain.

Ruler label density follows the available width and measured text size. Major endpoint labels
have priority, then other major labels, then minor labels that fit. Visible labels remain inside
the ruler with space between them; a label wider than the available ruler is hidden. All tick
lines, original label text and tick titles remain present. A resize or font-size change restores
labels when room becomes available. Labels share the top ruler line; minor tick rules occupy the
lower half.

Ranged regions keep their exact clipped proportions, including very short intervals. Their
visual borders do not enlarge the button's hit box or cover a neighbor. Point markers retain a
2px minimum width. Narrow regions keep complete accessible labels; the native playhead range
remains available for precise keyboard navigation.

## Binding and command settlement

The binding remains authoritative. A subscription notification schedules at most one repaint
per animation frame; explicit `update()` repaints immediately. See the
[shared presenter shape](/uikit/api/#the-shared-presenter-shape) for common ownership and
cleanup rules. Ruler size observation only repositions labels; it does not pull a new state,
rebuild regions or change seek values. Browsers without `ResizeObserver` use a window resize
listener; ordinary playhead paints do not measure labels.

`seek()` and `selectRegion()` are optional and may return promises. When present, lane clicks and
region buttons call them and repaint after settlement; a rejected command is routed to
`onError`. Without `seek()`, the hidden range is removed from interaction. Without
`selectRegion()`, every region button is disabled.

<details class="component-section">
<summary>API</summary>

`mountTimeline(host, binding, options?)` accepts an `HTMLElement` or `ShadowRoot` and returns a
`TimelineHandle`.

**State**

| Member | Kind | Description |
|---|---|---|
| `duration` | `number` | Complete domain. Non-finite values fall back to `1`; zero and negative values normalize to `Number.EPSILON`. |
| `viewport?` | `TimelineRange` | Visible `{start, end}` interval, clamped to `0…duration`; it must have `end > start`, otherwise the full duration is used. |
| `playhead?` | `number` | Position of the playhead and seek input. Non-finite values become `0`; the line is hidden outside the viewport. |
| `ticks?` | `readonly TimelineTick[]` | Domain ticks. Empty/duplicate ids, non-finite positions, and ticks outside the viewport are skipped. Omission generates major ticks. |
| `selection?` | `TimelineRange` | Display-only selected interval, clamped to the viewport and hidden unless `end > start`. |
| `loop?` | `TimelineRange` | Display-only loop interval, clamped to the viewport and hidden unless `end > start`. |
| `regions` | `readonly TimelineRegion[]` | Required ranged regions and point markers. An omitted `end` makes a marker; ranges are clipped to the viewport. |
| `disabled?` | `boolean` | Strict `true` disables seeking and every region button without removing painted state. |

`TimelineTick` contains required `id` and `position`, optional `label`, and optional
`level: 'major' | 'minor'`. `TimelineRegion` contains required `id` and `start`, plus optional
`end`, `label`, `color`, `selected`, and `disabled` fields. A region's strict `selected: true`
sets its pressed state; strict `disabled: true` disables only that region.

**Binding**

| Member | Kind | Description |
|---|---|---|
| `snapshot()` | `() => TimelineState` | Required pull port, read on mount and every update. A thrown error reaches `onError` and leaves the current DOM unchanged. |
| `seek?(position)` | `(number) => void \| Promise<void>` | Receives an absolute, viewport-clamped position from lane pointer input or the hidden range. |
| `selectRegion?(id, options)` | `(string, TimelineSelectOptions) => void \| Promise<void>` | Receives the region id and `{additive}`, which is true for Ctrl/Command-click. |
| `subscribe?(notify)` | `(notify: () => void) => () => void` | Optional change subscription. Its disposer is called by `destroy()` and on same-host remount. |

**Options**

| Member | Kind | Default | Description |
|---|---|---|---|
| `label` | `string` | `'Timeline'` | Accessible name of the root group and prefix for the hidden playhead range. |
| `majorStep` | `number` | Derived readable interval | Fixed generated-tick interval. Non-positive or non-finite values use the derived interval. |
| `keyboardStep` | `number` | `majorStep / 4` | Step of the hidden range. Non-positive or non-finite values use the default. |
| `formatPosition` | `(position: number) => string` | Adaptive numeric formatter | Formats generated tick labels and seek `aria-valuetext`; supplied tick labels take precedence. |
| `classNames` | `TimelineClassNames` | `{}` | Adds compatibility classes for `root`, `ruler`, `tick`, `tickLabel`, `lane`, `region`, `marker`, `label`, `selection`, `loop`, `playhead`, and `seek`. |
| `parts` | `TimelineParts` | `{}` | Adds part tokens for the same twelve node roles. |
| `onError` | `(error: unknown) => void` | — | Receives snapshot, command, subscription, and cleanup failures. |
| `stylesheet` | `boolean` | `true` | Installs the presenter's stylesheet unless explicitly `false`, for a light-DOM host that cannot inject CSS into its page. |

**Handle**

| Member | Kind | Description |
|---|---|---|
| `element` | `HTMLElement` | Presenter-owned `.wui-timeline` root. |
| `ruler` | `HTMLElement` | Always-present ruler node. |
| `lane` | `HTMLElement` | Always-present region and overlay lane. |
| `seek` | `HTMLInputElement` | Always-created visually hidden range; disabled and interaction-hidden when `seek` is absent. |
| `regionElement(id)` | `(string) => HTMLButtonElement \| undefined` | Returns a currently rendered region or marker button by id. |
| `update()` | `() => void` | Re-reads state immediately and repaints; becomes a no-op after destruction. |
| `destroy()` | `() => void` | Idempotently cancels a pending frame, disposes the subscription and resize observation/listener, and removes presenter DOM and stylesheet. |

**Accessibility.** The root is a labelled `role="group"`; the ruler and all display-only overlays
are hidden from the accessibility tree. Regions are native buttons with an accessible label and
`aria-pressed`, and disabled state uses the native `disabled` attribute. The playhead control is
a visually hidden labelled range, so native Arrow, Page, Home, and End behavior uses
`keyboardStep`; its formatted position is exposed through `aria-valuetext`. Lane pointer seeking
has no separate keyboard gesture—the range is its keyboard equivalent. Focus outlines are
painted on the lane or region without rewriting unrelated caller nodes.

background (including `transparent`), foreground, accent, outer border and corner radius.

The installed stylesheet resolves presenter-specific `--wm-timeline-*` tokens through shared
`--wm-*` values and then literals. A region's `color` is written to the internal
`--wui-timeline-region-color`; it takes precedence over the theme's region fill and border
source. Region borders use an inset shadow so they do not alter geometry. Forced-colors mode
uses an inward outline, including a distinct selected/focus outline, because shadows may be suppressed. `--wm-timeline-marker-width` is read from each marker's inline width declaration.

Every mount installs `timelineStyle` by default. With `stylesheet: false`, install the exported
stylesheet yourself or supply equivalent structural styling. Style these canonical classes and
parts after the installed style when you need caller-owned overrides. Ticks publish
`data-label-visible="true|false"`; hiding a visual ruler label never shortens region labels or
seek `aria-valuetext`.
