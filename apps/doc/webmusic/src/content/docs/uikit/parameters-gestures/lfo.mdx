`mountLfo()` renders a run toggle, four waveform buttons, rate and depth ranges, and a waveform
with a phase head. The caller owns oscillator time, scheduling and modulation targets; the
presenter paints `LfoState` and calls one structural command per control.

Use [envelope](/uikit/parameters-gestures/envelope/) for one-shot ADSR shaping or
[parameter](/uikit/parameters-gestures/parameter/) for independent values. The Live Demo advances
`phase` in caller code only while `running`; [`<score-synth-panel>`](/score/element/play/score-synth-panel/)
already provides the production composition.

## Import

```ts
import {mountLfo} from '@webmusic/ui/lfo';

const handle = mountLfo(host, {
  snapshot: () => store.lfo,
  setRunning: (running) => clock.setRunning(running),
  setShape: (shape) => store.setShape(shape),
  setRate: (rate) => store.setRate(rate),
  setDepth: (depth) => store.setDepth(depth),
  subscribe: (notify) => store.subscribe(notify),
});
```

## Commands and phase ownership

The presenter normalizes each snapshot, then overlays the latest unsettled command of each kind
for optimistic paint. Running, shape, rate and depth use independent revision counters, so an old
rate promise cannot clear a newer rate command and never blocks a simultaneous shape command.
After the latest command settles, the presenter re-reads authoritative state.

`phase` has no presenter command: an external clock, audio graph or animation owner advances it
and calls the binding subscription. `update()` is re-entrancy-safe and bounded to 32 passes. See
the [shared presenter shape](/uikit/api/#the-shared-presenter-shape) for the common lifecycle.

<details class="component-section">
<summary>API</summary>

`mountLfo(host, binding, options?)` accepts an `HTMLElement` or `ShadowRoot` and returns a
`MountedLfoHandle`.

**State**

| Member | Kind | Description |
|---|---|---|
| `shape` | `'sine' \| 'triangle' \| 'square' \| 'saw'` | Selects button state, chip glyph and generated waveform; unknown values normalize to `'sine'`. |
| `rate` | `number` | Frequency in hertz, clamped to the native input's `0.05…12` range. |
| `depth` | `number` | Normalized modulation depth clamped to `0…1`; scales waveform amplitude. |
| `phase` | `number` | Normalized external cycle position clamped to `0…1`; sets the phase-head x coordinate. |
| `running` | `boolean` | Strict `true` selects the pause icon, the stop accessible action and `aria-pressed="true"`. |
| `disabled?` | `boolean` | Strict `true` disables every button and range input and dims the root. |

**Binding**

| Member | Kind | Description |
|---|---|---|
| `snapshot()` | `() => LfoState` | Required pull port read on mount, notification, command settlement and `update()`. |
| `setRunning(running)` | `(boolean) => void \| Promise<void>` | Required run/stop command. |
| `setShape(shape)` | `(LfoShape) => void \| Promise<void>` | Required waveform command. |
| `setRate(rate)` | `(number) => void \| Promise<void>` | Required frequency command receiving the native range value. |
| `setDepth(depth)` | `(number) => void \| Promise<void>` | Required normalized depth command. |
| `subscribe?(notify)` | `(notify: () => void) => () => void` | Optional external-state subscription released by `destroy()`. |

**Options**

| Member | Kind | Default | Description |
|---|---|---|---|
| `label` | `string` | `'LFO'` | Accessible name of the root group. |
| `runLabel` | `string` | `'Run'` | Run button accessible name while stopped. |
| `stopLabel` | `string` | `'Stop'` | Run button accessible name while running. |
| `classNames` | `LfoClassNames` | `{}` | Adds compatibility classes for root, controls, inputs, values and waveform nodes. |
| `parts` | `LfoParts` | `{}` | Adds tokens beside all canonical LFO parts. |
| `formatRate` | `(rate: number) => string` | `` `${rate.toFixed(2)}Hz` `` | Formats visible rate and `aria-valuetext`; thrown errors go to `onError`. |
| `formatDepth` | `(depth: number) => string` | Integer percent | Formats visible depth and `aria-valuetext`; thrown errors go to `onError`. |
| `onError` | `(error: unknown) => void` | — | Receives snapshot, formatter, command, subscription, stabilization and cleanup failures. |
| `stylesheet` | `boolean` | `true` | Installs the presenter's stylesheet unless explicitly `false`, for a light-DOM host that cannot inject CSS into its page. |

**Handle**

| Member | Kind | Description |
|---|---|---|
| `element` | `HTMLElement` | Presenter-owned `.wui-lfo` root. |
| `controls.run` | `HTMLButtonElement` | Run/stop toggle. |
| `controls.shapes` | `HTMLElement` | Shape button group. |
| `controls.rateInput` | `HTMLInputElement` | Native rate range. |
| `controls.rateValue` | `HTMLElement` | Formatted, aria-hidden rate readout. |
| `controls.depthInput` | `HTMLInputElement` | Native depth range. |
| `controls.depthValue` | `HTMLElement` | Formatted, aria-hidden depth readout. |
| `controls.wave` | `HTMLElement` | Waveform viewport. |
| `controls.curve` | `SVGPolylineElement` | Generated waveform curve. |
| `controls.head` | `SVGLineElement` | Current phase head. |
| `update()` | `() => void` | Re-reads and repaints through the bounded update loop. |
| `destroy()` | `() => void` | Idempotently invalidates pending commands and removes listeners, subscription, root and stylesheet. |

**Accessibility.** The root and shape set are named groups. Run is a native icon button whose
dynamic name is in `aria-label` and `title` and whose `aria-pressed` follows `running`; every shape is a labelled toggle button with `aria-pressed`. Rate and depth are
native labelled ranges whose custom formatted values are mirrored in `aria-valuetext`; visible
readouts and all SVG glyphs are hidden from assistive technology. Disabled state reaches every
interactive node and drops the root to 30% opacity, and `:focus-visible` draws a 2px outline
inside buttons and inputs.

<summary>Styling</summary>

Use the shared [surface and palette tokens](/uikit/#theme-with-css-custom-properties) for
background (including `transparent`), foreground, accent, outer border and corner radius.
Presenter-specific tokens below take precedence within their documented roles.

The presenter installs `lfoStyle` unless `stylesheet: false`. Controls and waveform buttons
wrap according to their container width. Range inputs can shrink below their preferred width;
long formatted values wrap onto additional lines while the waveform keeps its configured height.
Run is a muted, unfilled icon button that inverts to ink while running. Formatted values use mono
type.
Supply the exported stylesheet or your own CSS from the host when opting out.

The waveform shares the component surface below a hairline: by default its background is
`--wm-surface` and its curve and phase head use `--wm-foreground`. Set `--wm-lfo-wave-background`

**Parts**

Canonical tokens are `root`, `row`, `run`, `shapes`, `shape`, `wave`, `curve`, and `head`. Each
rate/depth label has `control label rate-control` or `control label depth-control`; each range has
`input rate` or `input depth`; each readout has `value rate-value` or `value depth-value`.
`LfoParts` adds its matching generic and specific tokens alongside all of them.
