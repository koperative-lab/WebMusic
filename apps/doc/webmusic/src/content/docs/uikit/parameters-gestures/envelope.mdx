`mountEnvelope()` renders an ADSR curve, filled area, three draggable SVG handles, a visual
readout and four native range inputs. It paints `EnvelopeSnapshot`; the caller owns envelope and
range state and commits complete `EnvelopeState` objects through `setEnvelope()`.

Use [LFO](/uikit/parameters-gestures/lfo/) for cyclic modulation or
[parameter](/uikit/parameters-gestures/parameter/) for independent scalar controls.
[`<score-synth-panel>`](/score/element/play/score-synth-panel/) already composes this presenter.

## Import

```ts
import {mountEnvelope} from '@webmusic/ui/envelope';

const handle = mountEnvelope(host, {
  snapshot: () => store.envelope,
  setEnvelope: (envelope) => store.setEnvelope(envelope),
  subscribe: (notify) => store.subscribe(notify),
});
```

## Geometry and command settlement

The viewbox has four equal horizontal segments. Attack occupies the first segment, decay the
second, sustain holds across the third, and release extends into the fourth. Each time stage is
scaled against its positive `*Max` range; sustain is clamped to `0…1`. The combined decay/sustain
handle edits both axes in one pointer gesture.

Pointer movement during a drag is applied at most once per animation frame, using only the latest
position; releasing the pointer applies the final position at once, and a cancelled drag drops a
pending one. Pointer and native-range input paints optimistically, calls `setEnvelope()` with a new complete
object, then re-reads the binding after the latest command settles. Earlier command settlements
cannot overwrite a newer gesture. Subscription and explicit updates use the same 32-pass bounded
repaint path. See the [shared presenter shape](/uikit/api/#the-shared-presenter-shape) for the
common lifecycle contract.

<details class="component-section">
<summary>API</summary>

`mountEnvelope(host, binding, options?)` accepts an `HTMLElement` or `ShadowRoot` and returns an
`EnvelopeHandle`.

**State**

Non-finite envelope values normalize to `0`. Non-positive or non-finite ranges use the defaults
shown below; curve geometry clamps values to each visible range without mutating caller state.

| Member | Kind | Description |
|---|---|---|
| `envelope` | `EnvelopeState` | Required ADSR value object painted and replaced as one command payload. |
| `envelope.attack` | `number` | Attack seconds; visible geometry clamps to `0…attackMax`. |
| `envelope.decay` | `number` | Decay seconds; visible geometry clamps to `0…decayMax`. |
| `envelope.sustain` | `number` | Sustain level clamped to `0…1` for geometry and input. |
| `envelope.release` | `number` | Release seconds; visible geometry clamps to `0…releaseMax`. |
| `ranges` | `EnvelopeRanges` | Required positive range maxima for time-stage scaling. |
| `ranges.attackMax` | `number` | Attack scale maximum; invalid values become `2`. |
| `ranges.decayMax` | `number` | Decay scale maximum; invalid values become `2`. |
| `ranges.releaseMax` | `number` | Release scale maximum; invalid values become `2`. |
| `disabled?` | `boolean` | Strict `true` disables all range inputs and pointer editing. |

**Binding**

| Member | Kind | Description |
|---|---|---|
| `snapshot()` | `() => EnvelopeSnapshot` | Required pull port read on mount, notification, command settlement and `update()`; failures go to `onError`. |
| `setEnvelope(envelope)` | `(EnvelopeState) => void \| Promise<void>` | Required command receiving a fresh complete ADSR object after pointer or range input. |
| `subscribe?(notify)` | `(notify: () => void) => () => void` | Optional external-state subscription released by `destroy()`. |

**Options**

| Member | Kind | Default | Description |
|---|---|---|---|
| `label` | `string` | `'Envelope'` | Accessible name of the root group. |
| `classNames` | `EnvelopeClassNames` | `{}` | Adds compatibility classes to root, SVG, grid, area, curve, handles, readout, inputs wrapper and inputs. |
| `parts` | `EnvelopeParts` | `{}` | Adds tokens beside the canonical parts for the same node set. |
| `onError` | `(error: unknown) => void` | — | Receives snapshot, command, subscription, stabilization and cleanup failures. |
| `stylesheet` | `boolean` | `true` | Installs the presenter's stylesheet unless explicitly `false`, for a light-DOM host that cannot inject CSS into its page. |

**Handle**

| Member | Kind | Description |
|---|---|---|
| `element` | `HTMLElement` | Presenter-owned `.wui-envelope` root. |
| `update()` | `() => void` | Re-reads and repaints the binding through the bounded update loop. |
| `destroy()` | `() => void` | Idempotently ends pointer capture and removes listeners, subscription, root and installed stylesheet. |

**Accessibility.** The root is a `role="group"` named by `label`. Four visually clipped native
ranges are labelled Attack, Decay, Sustain and Release and expose formatted `aria-valuetext`;
their native keys are the keyboard-equivalent editing path. SVG curve, handles and visual readout
are `aria-hidden`, so they do not duplicate the ranges. Focus on a range highlights its related
SVG handle with a 2px ink ring. Disabled state reaches every native input and drops the root to
30% opacity; forced-colors rules retain curve, handle and focus contrast.

<details class="component-section">
<summary>Styling</summary>

Use the shared [surface and palette tokens](/uikit/#theme-with-css-custom-properties) for
background (including `transparent`), foreground, accent, outer border and corner radius.
Presenter-specific tokens below take precedence within their documented roles.

The presenter installs `envelopeStyle` unless `stylesheet: false`. The SVG fills its container
width and keeps the height set by `--wm-envelope-height`. The wrapping ADSR readout occupies a
separate row below the plot, divided from it by a hairline, and adds to the total height. Drag
coordinates use the SVG's bounds measured when the press starts, so wrapping text and container
resizing do not change the time/level mapping.
Supply the exported stylesheet or your own CSS from the host when opting out.

The plot shares the component surface: by default its background is `--wm-surface` and its
curve and handles use `--wm-foreground`, with no inner border. To invert the plot, set
`--wm-envelope-background` and `--wm-envelope-foreground` (or the curve and handle tokens)
together; handle outlines follow the plot background so they stay paired. The readout below uses
ordinary muted foreground tokens.

**Tokens**

| Property | Falls back to | Default | Controls |
|---|---|---|---|
| `--wm-envelope-border` | `--wm-control-border` → `--wm-border` | `light-dark(#d8d8d8, #333)` | Hairline between the plot and the readout. |
| `--wm-control-border` | `--wm-border` | `light-dark(#d8d8d8, #333)` | Shared line fallback for the divider and grid. |
| `--wm-envelope-radius` | `--wm-control-radius` | `0` | Plot corners. |
| `--wm-control-radius` | literal | `0` | Shared radius fallback. |
| `--wm-envelope-background` | `--wm-surface` | `light-dark(#fff, #111)` | Plot background; the outer root uses the shared `--wm-component-*` surface. |
| `--wm-envelope-foreground` | `--wm-foreground` | `light-dark(#111, #eee)` | Root current color and curve/handle fallback. |

**Classes**

`classNames` adds compatibility classes without replacing canonical names.

| Node | Canonical class | `classNames` key |
|---|---|---|
| Root | `.wui-envelope` | `root` |
| SVG | `.wui-envelope__svg` | `svg` |
| Each guide | `.wui-envelope__grid` | `grid` |
| Filled polygon | `.wui-envelope__area` | `area` |
| Curve polyline | `.wui-envelope__curve` | `curve` |
| Each handle | `.wui-envelope__handle` | `handle` |
| Visual readout | `.wui-envelope__readout` | `readout` |
| Clipped input wrapper | `.wui-envelope__inputs` | `inputs` |
| Each native range | `.wui-envelope__input` | `input` |

Runtime modifiers are `.is-disabled` on the root and `.is-dragging` / `.is-focused` on handles.

**Parts**

The canonical part tokens are `root`, `svg`, `grid`, `area`, `curve`, `handle`, `readout`, `inputs`
and `input`; `EnvelopeParts` adds tokens beside each matching name and de-duplicates them.
