The UI Kit publishes presenters, not Custom Elements. Pick a functional group
below, then mount the presenter against any compatible Headless object, store,
controller or binding. Each card links to the entry's own page.
The groups describe UI responsibilities; they do not change npm import paths.
Presenters with no current Score Element consumer are independently usable.
