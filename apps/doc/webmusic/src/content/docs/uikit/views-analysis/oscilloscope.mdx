`mountOscilloscope()` draws one bounded waveform window and owns the controls
for timebase, trigger, freeze and probing. The caller supplies sampled data
and chooses whether those controls alter capture or only the displayed frame.
The presenter does not open an audio graph or know a player's clip position.
For a ready player-connected composition, use
[`<audio-oscilloscope>`](/audio/element/analyze/audio-oscilloscope/).

## Import

```ts
import {mountOscilloscope, type OscilloscopeState} from '@webmusic/ui/oscilloscope';

const state: OscilloscopeState = {
  trace: {samples: new Float32Array([0, 0.4, 0, -0.4, 0]), timebaseMs: 10, triggered: true, silent: false},
  availableTimeMs: 50,
  timebaseMs: 10,
  triggerLevel: 0,
  triggerEdge: 'rising',
  frozen: false,
  status: 'live',
};
const handle = mountOscilloscope(host, {
  snapshot: () => state,
  setFrozen: (value) => { state.frozen = value; handle.update(); },
  setTimebaseMs: (value) => { state.timebaseMs = value; handle.update(); },
  setTriggerLevel: (value) => { state.triggerLevel = value; handle.update(); },
  setTriggerEdge: (value) => { state.triggerEdge = value; handle.update(); },
  probe: (timeMs, amplitude) => inspect(timeMs, amplitude),
});
// Call handle.update() after replacing the trace; destroy on removal.
```

The caller owns `host`, `state`, the signal and `inspect()`. The commands
above merely update demonstration state; a real caller projects a new trace
from its own source and notifies the presenter. An optional `subscribe()`
binding may call `update()` when that state changes.

## Window and trigger

`trace.samples` are linear sample amplitudes along `trace.timebaseMs`
milliseconds. The presenter plots exactly that caller-provided window. It
does not detect a crossing or retune an analyser: `triggerEdge`,
`triggerLevel`, `availableTimeMs` and `timebaseMs` are caller state and command
inputs. The [shared presenter shape](/uikit/api/#the-shared-presenter-shape)
governs host replacement and cleanup. New source identity and obsolete trace
rejection belong to the caller; `destroy()` removes this presenter's observer,
subscription, listeners, nodes and installed style, not the audio source.

Time and Amplitude occupy fixed readout slots; missing measurements show `—`.
The surface omits a repeated title. Routine live, paused and frozen messages
are hidden, while unavailable, No signal and No matching edge feedback remains
visible. Loading and waiting use square indicators with accessible descriptions. Freeze keeps its label and reflects its state with
`aria-pressed`.

<details class="component-section">
<summary>API</summary>

**State and trace**

| Member | Kind | Default | Description |
|---|---|---|---|
| `trace` | `OscilloscopeTrace?` | absent | Current `{samples, timebaseMs, triggered, silent}` window. With no trace, the plot has no waveform. |
| `trace.samples` | `ArrayLike<number>` | required in trace | Linear amplitudes painted from left to right; the caller owns the data. |
| `trace.timebaseMs` | `number` | required in trace | Elapsed milliseconds across the displayed sample window. |
| `trace.triggered` | `boolean` | required in trace | Whether the caller found an eligible edge; an unmatched active trigger reports No matching edge. |
| `trace.silent` | `boolean` | required in trace | Whether the sampled window is silent; displays "No signal" rather than a matching-edge message. |
| `availableTimeMs` | `number` | required | Maximum sampled window available for the timebase control; invalid or non-positive values fall back to `100`. |
| `timebaseMs` | `number` | required | Requested visible milliseconds, clamped in the control to the available window. |
| `triggerLevel` | `number` | required | Linear amplitude threshold shown by the trigger line and horizontal fader (`-1..1`). |
| `triggerEdge` | `'off' \| 'rising' \| 'falling'` | required | Selected native edge control. `off` is free-run display. |
| `frozen` | `boolean` | required | Freeze button state; the caller decides whether to keep replacing `trace`. |
| `status` | `'loading' \| 'waiting' \| 'live' \| 'paused' \| 'unavailable' \| 'frozen'` | required | Signal state. `loading` shows the busy four-cell animation; `waiting` shows the outlined square indicator with accessible status text; unavailable diagnostics remain visible, while routine live/paused/frozen text is hidden. |

**Binding, options and handle**

| Member | Kind | Default | Description |
|---|---|---|---|
| `snapshot()` | `() => OscilloscopeState` | required | Reads the latest caller-owned trace and controls. |
| `setFrozen(value)` | `(boolean) => void` | required | Called by the native Freeze button. |
| `setTimebaseMs(value)` | `(number) => void` | required | Called by the horizontal timebase fader, in milliseconds. |
| `setTriggerLevel(value)` | `(number) => void` | required | Called by the horizontal trigger fader, in linear sample amplitude. |
| `setTriggerEdge(value)` | `(OscilloscopeTriggerEdge) => void` | required | Called by the rising/falling/off select. |
| `probe(timeMs, amplitude)` | `(number, number \| undefined) => void` | optional | Reports a changed probe position and nearest sample amplitude, if present. Time is relative to the displayed window. |
| `subscribe(notify)` | `(callback) => () => void` | optional | Caller notifications for repaint; the handle also offers `update()`. |
| `label` | `string` | `'Oscilloscope'` | Accessible group name. |
| `onError` | `(unknown) => void` | absent | Receives snapshot, command, drawing, resize or cleanup failures. |
| `stylesheet` | `boolean` | `true` | Install this presenter's stylesheet for this mount. |
| `element` | `HTMLElement` | mounted root | Group root with `part="root surface"`. |
| `selectedTimeMs` | `number` | `0` | Read-only current probe position from the displayed window's left edge. |
| `update()` | `() => void` | - | Read `snapshot()` and redraw the display and controls. |
| `destroy()` | `() => void` | - | Release observer, subscription, controls, nodes and owned style. |

**Accessibility.** The canvas is a focusable slider named "Inspect waveform
time", with the selected time and optional amplitude in `aria-valuetext` and
a matching text readout outside the canvas. Pointer movement probes the
window. Arrow keys move by one percent, Shift+Arrow by ten percent, and
Home/End select the ends. Freeze is a native `aria-pressed` button; trigger
and timebase use labelled rectangular horizontal UIKit faders. Their slider
ARIA uses actual amplitudes and milliseconds. Trigger has a `0.05` keyboard
step; timebase has a `0.5` ms step between `min(1, availableTimeMs)` and the
available window. Home/End select the bounds. Readout
outputs use `aria-live="off"`; diagnostic status is a live status region.

<details class="component-section">
<summary>Styling</summary>

Loading and waiting feedback use the shared [Status animation and tokens](/uikit/layout-feedback/status/), including reduced-motion support. The exported stylesheet includes that feedback style.

The public root class is `.wui-oscilloscope`. Public parts are `root surface`,
`header`, `readout`, `plot`, `controls`, `freeze`, `timebase`,
`trigger-level`, `trigger-edge` and `status`. There are no `classNames` or
`parts` mount options; internal `.wui-oscilloscope__*` selectors describe
implementation nodes. `stylesheet:false` skips this mount's stylesheet but
does not remove caller-owned or previously installed CSS.

| Token | Fallback | Controls |
|---|---|---|
| `--wm-oscilloscope-foreground` | `--wm-foreground`, then dark ink | Root text. |
| `--wm-oscilloscope-muted` | `--wm-foreground-muted`, then `#666` | Secondary text, axes and grid. |
| `--wm-oscilloscope-height` | `11rem` | Plot height, minimum `7rem`. |
| `--wm-oscilloscope-plot-background` | `--wm-surface-muted`, then `#f3f3f3` | Canvas background. |
| `--wm-oscilloscope-accent` | inherited `--wm-fader-fill`, then `--wm-accent`, then `#999` | Legacy fader-fill override; an explicit value takes precedence over the shared fill. |
| `--wm-oscilloscope-border` | `--wm-border`, then gray | Native select and button borders. |
| `--wm-oscilloscope-control-background` | `--wm-surface`, then white | Select and button backgrounds. |
| `--wm-oscilloscope-selected-background`, `--wm-oscilloscope-selected-border` | `--wm-accent` / `--wm-control-border`, then gray | Pressed Freeze button. |
| `--wm-analysis-control-size` | `1.5rem` | Compact controls and horizontal fader thickness. |
| `--wm-fader-*` | shared fader defaults | Fader track, fill, thumb and corners. |
| `--wm-focus` | `--wm-foreground`, then `#444` | Focus outlines. |

The default palette is achromatic. The canvas is cleared transparently so its
background token remains effective; trace and probe use the resolved foreground,
and axes/grid use the resolved muted color. Its geometry follows the caller's
trace and rendered host width. Timebase and trigger sliders retain the shared
`fader` part alongside their named parts; use selectors such as
`[part~="timebase"]`.

</details>
