`mountRecorder()` renders one row of square icon buttons: a required record toggle, an optional
playback toggle, a compact input-level bar and optional format-specific export buttons, plus a
status line that is announced but drawn only for an error. It paints
`RecorderState`; the caller remains responsible for media permission, capture, playback, file
creation, and persistence.

Use [meter](/uikit/mixing-capture/meter/) for continuous level or spectrum monitoring without a
capture workflow, or [mixer](/uikit/mixing-capture/mixer/) for channel gain and routing controls.
The [`<score-recorder>`](/score/element/play/score-recorder/) and
[`<audio-recorder>`](/audio/element/play/audio-recorder/) elements compose this
presenter; mount it directly around a custom recorder state machine.

## Import

```ts
import {mountRecorder} from '@webmusic/ui/recorder';

const handle = mountRecorder(host, {
  snapshot: () => store.recorder,
  toggleRecording: () => recorder.toggle(),
  subscribe: (notify) => store.subscribe(notify),
});
```

## Async capture commands

Every command may return a promise. The presenter invokes it without owning a competing state
machine, then repaints after settlement. A synchronous throw or rejection from the current command goes
to `onError`; an older command can refresh accepted state but cannot report over a newer command.
Settlement after destruction or replacement is ignored. Errors from `onError` are contained.
Publish intermediate `busy`, `recording`, `playing`, level, and status snapshots through
`subscribe()` when the UI must change while work is pending. The common binding ownership and
same-host lifecycle are documented in the
[shared presenter shape](/uikit/api/#the-shared-presenter-shape).

`togglePlayback` controls whether the Play button exists. Export buttons require both nonempty
`exportFormats` and an `export(format)` binding. `busy` or `disabled` blocks all commands.
Playback and export additionally use `canPlay` and `canExport`; an active take remains stoppable
even when `canPlay` becomes false. The presenter borrows all recorder state and resources.

<details class="component-section">
<summary>API</summary>

`mountRecorder(host, binding, options?)` accepts an `HTMLElement` or `ShadowRoot` and returns a
`RecorderHandle`. The level is clamped to `0…1`; omitting it hides the visual meter.

**State**

| Member | Kind | Description |
|---|---|---|
| `recording` | `boolean` | Required. Selects the record or stop icon, accessible name, pressed state, recording colour and generated recording status. |
| `busy?` | `boolean` | Strict `true` blocks every command and sets root/record `aria-busy`. |
| `playing?` | `boolean` | Strict `true` applies the playback modifier, pressed state, stop icon and generated playback status. |
| `level?` | `number` | Normalized input level written to `--wui-recorder-level`. Omission hides the meter. |
| `recordedCount?` | `number` | Count in the generated `recording… <count>` status; defaults there to `0`. |
| `takeCount?` | `number` | Count printed by generated captured/playback status. When explicit availability is absent, any defined value enables play and export, including `0`. |
| `status?` | `string` | Overrides the generated status or supplies the accessible loading/waiting description. Announced only; the surface draws no status prose except an error. |
| `elapsed?` | `string` | Short mono readout beside the stop icon while recording, such as `0:03`. Omitted shows the icon alone. |
| `statusKind?` | `'loading' \| 'waiting' \| 'error'` | Selects shared passive feedback. When omitted, `busy` uses loading; other states announce their status text without drawing it. |
| `canPlay?` | `boolean` | Explicit playback availability. When absent, falls back to whether `takeCount` is defined. |
| `canExport?` | `boolean` | Explicit availability for every export button. When absent, falls back to whether `takeCount` is defined. |
| `disabled?` | `boolean` | Strict `true` blocks all commands and applies root `aria-disabled`. |

Loading and waiting use the shared square animations, with visually hidden live descriptions.
Ready status text is visually hidden too; only an error line is drawn, in the row after the
controls. Feedback does not itself block commands; `busy` and `disabled` retain
that responsibility. The animations follow reduced-motion preferences.

Without `status`, the fallback order is recording count, playing-take text, captured-take text
when `takeCount` is defined, then `Ready`. Finite counts become nonnegative integers; invalid
counts are omitted. Finite levels clamp to 0–1 and invalid supplied levels paint as 0.

**Binding**

| Member | Kind | Description |
|---|---|---|
| `snapshot()` | `() => RecorderState` | Required pull port read on mount, notification, command fulfillment, and explicit `update()`. Errors are sent to `onError` and leave the last successful paint. |
| `toggleRecording()` | `() => void \| Promise<void>` | Required command called by the record toggle in both directions. |
| `togglePlayback?()` | `() => void \| Promise<void>` | Optional command. Its presence creates the playback toggle. |
| `export?(format)` | `(string) => void \| Promise<void>` | Optional command receiving the clicked `exportFormats` id. |
| `subscribe?(notify)` | `(notify: () => void) => () => void` | Optional subscription. Its disposer is called during destroy or same-host replacement. |

**Options**

| Member | Kind | Default | Description |
|---|---|---|---|
| `exportFormats` | `readonly RecorderExportFormat[]` | `[]` | Snapshotted `{id, label, readout?}` strings. With `export()`, creates one download icon button per format; its id reaches the command, its label names the download, and `readout` is the short mono text beside the icon (`MID`, `XML`, `WAV`). Without `readout`, a label of at most four characters is used, else an alphanumeric id of at most four characters in upper case, else the label. |
| `label` | `string` | `Recorder` | Accessible root group name. |
| `recordLabel` / `stopRecordingLabel` | `string` | `Record` / `Stop recording` | Accessible record-toggle names. |
| `playLabel` | `string` | `Play take` | Accessible playback-toggle name. |
| `stopPlaybackLabel` | `string` | `playLabel` | Optional name while playing. Set it explicitly, for example to `Stop playback`, to enable a distinct stop label. |
| `meterLabel` | `string` | `Input level` | Accessible progressbar name. |
| `exportsLabel` | `string` | `Export take` | Accessible export-group name. |
| `statusLabel` | `string` | `Recorder status` | Accessible live-status name. |
| `classNames` / `parts` | `RecorderClassNames` / `RecorderParts` | `{}` | Add classes or part tokens for `root`, `record`, `play`, `meter`, `level`, `exports`, `export`, and `status`, preserving canonical hooks. |
| `onError` | `(error: unknown) => void` | — | Receives snapshot/current-command errors and errors retiring a prior mount. Callback faults are contained. Current mount setup and final cleanup failures can throw after best-effort rollback or release. |
| `stylesheet` | `boolean` | `true` | Installs the presenter's stylesheet unless explicitly `false`, for a light-DOM host that cannot inject CSS into its page. |

**Handle**

| Member | Kind | Description |
|---|---|---|
| `element` | `HTMLElement` | Presenter-owned `.wui-recorder` root. |
| `update()` | `() => void` | Re-reads state and repaints every control; becomes a no-op after destruction. |
| `destroy()` | `() => void` | Idempotently retires commands, removes listeners, disposes the subscription and removes root/style. Attempts every cleanup before rethrowing the first failure; retains borrowed recorder resources. |

**Accessibility.** The root is a named group. Record and playback are native icon buttons whose
pressed state follows capture/playback; each name is in `aria-label` and `title`, and the icons
are hidden from assistive technology. Recording has a dynamic accessible name; playback
uses `playLabel` unless an explicit `stopPlaybackLabel` supplies its playing name. Export buttons
are named `Download <label>`; their mono readout is visible text beside the icon.
The optional input level uses `role="progressbar"`, bounds 0–1 and a percentage value text;
its decorative fill is hidden from accessibility. Normal status is a named, atomic, polite
live region; passive loading/waiting descriptions are polite, and errors use an alert.
Busy/disabled state blocks every native command; keyboard focus remains visible.

<details class="component-section">
<summary>Styling</summary>

Use the shared [surface and palette tokens](/uikit/#theme-with-css-custom-properties) for
background (including `transparent`), foreground, accent, outer border and corner radius.
Presenter-specific tokens below take precedence within their documented roles.

The installed stylesheet resolves presenter-specific properties through shared `--wm-*` tokens
and then literals. `--wui-recorder-level` is presenter-owned output written on the level node, not
a theme input. The mount installs `recorderStyle` by default; set `stylesheet: false` to omit it
and supply the exported stylesheet or your own CSS from the host. Canonical classes, fixed
compatibility classes, and canonical parts are always installed beside any `classNames` and
`parts` options. Rules use `:where()`, so application CSS wins.

The controls form one row, one control height tall, that never wraps: record, playback, the
level bar and the export group sit edge to edge, with hairlines before the level bar and the
export group. On a narrow host the row scrolls sideways without a visible scrollbar. Icon buttons
are muted and unframed when idle, ink on a raised fill on hover, inverted when pressed, and 30%
opaque when disabled; focus is a 2px ink outline drawn inside the button. A pressed Record button
and the level fill while recording use the recording colour; otherwise the level fill is muted.
The optional level meter stays hidden when the binding supplies no level. Width changes use
CSS and do not remount the recorder or alter recording/playback state.

**Tokens**

| Property | Falls back to | Default | Controls |
|---|---|---|---|
| `--wm-recorder-padding` | literal | `0` | Root inset; the row sits edge to edge inside the frame. |
| `--wm-recorder-height` | `--wm-control-size` → `--wui-row-h` | `2rem` | Height and minimum width of every icon button and height of the level bar, so the row reads as one strip. |
| `--wm-recorder-meter-width` | literal | `90px` | Level bar basis width; it may shrink to `2rem`. Its height follows the control size above. |
| `--wm-recorder-border` | `--wm-border` | `light-dark(#d8d8d8, #333)` | Root border. |
| `--wm-control-border` | `--wm-border` | `light-dark(#d8d8d8, #333)` | Hairlines before the level bar and the export group. |
| `--wm-recorder-background` | `--wm-surface` | `light-dark(#fff, #111)` | Root background. |
| `--wm-recorder-text` | `--wm-foreground` | `light-dark(#111, #eee)` | Root text. |
| `--wm-foreground` | literal | `light-dark(#111, #eee)` | Hovered icon, pressed playback fill and focus outline. |
| `--wm-foreground-muted` | literal | `light-dark(#777, #aaa)` | Idle icons and the level fill when not recording. |
| `--wm-surface-muted` | literal | `light-dark(#f3f3f3, #1c1c1c)` | Hover fill and the level track fallback. |

| `--wm-focus-ring` | literal | `2px solid var(--wm-foreground)` | Focus outline, drawn inside the button. |

**Classes**

| Node | Canonical class | Present when | Fixed compatibility class |
|---|---|---|---|
| Root | `.wui-recorder` | Always; `.is-recording`, `.is-playing`, `.is-busy` and `.is-disabled` follow state | `.wrap` |
| Any action | `.wui-recorder__button` | Record, playback, and every export | Format id is also a class on export buttons |
| Record | `.wui-recorder__record` | Always | `.rec`; `.armed` while recording |
| Playback | `.wui-recorder__play` | `togglePlayback` exists | `.play`; `.on` while playing |
| Meter track | `.wui-recorder__meter` | Always, hidden when level is absent | `.meter` |
| Level fill | `.wui-recorder__level` | Always | `.level` |
| Export container | `.wui-recorder__exports` | Export binding and formats exist | — |
| Status | `.wui-recorder__status` | Always; carries `data-kind` (`ready`, `loading`, `waiting` or `error`) and is visually hidden unless `error` | `.status` |

**Parts**

| Node | Canonical part | Present when |
|---|---|---|
| Root | `root` | Always |
| Record button | `record` | Always |
| Playback button | `play` | `togglePlayback` exists |
| Meter track | `meter` | Always, possibly hidden |
| Level fill | `level` | Always |
| Export group | `exports` | Export binding and formats exist |
| Export button | `export` | One per configured export format |
| Status | `status` | Always |

`classNames` adds classes beside these canonical classes. `parts` adds tokens beside each
canonical part, with duplicate tokens removed. Accessible names use the corresponding label options.
