`mountStatus()` paints caller-owned `StatusState` as a shared loading, waiting, empty, or failure surface.
Loading displays four square cells in sequence; waiting displays a slowly breathing square outline.
Both use the current foreground color and retain their messages for assistive technology.
The `ready` state hides the surface, so a consumer can leave it mounted across the entire loading
lifecycle without branching its DOM.

Use it directly beside caller content, or supply the same State through
[`CanvasStageBinding.status()`](/uikit/layout-feedback/stage/) when feedback must overlay a canvas.

## Import

```ts
import {mountStatus} from '@webmusic/ui/status';

const handle = mountStatus(host, {
  snapshot: () => store.status,
  subscribe: (notify) => store.subscribe(notify),
});
```

## State ownership

The binding stays authoritative: notification and `handle.update()` both re-read `snapshot()`.
Changing `kind` changes visibility, animation, and live-region behavior. Use `loading` for active
preparation and `waiting` while an input or source is unavailable. Loading and waiting messages
are visually hidden; empty and error messages remain visible. Updates retain the same indicator
and message nodes, and unchanged notifications do not restart animations or rewrite announcements.
The rest of mounting and cleanup follows the
[shared presenter shape](/uikit/api/#the-shared-presenter-shape).

<details class="component-section">
<summary>API</summary>

**State**

| Member | Kind | Description |
|---|---|---|
| `kind` | `'ready' \| 'loading' \| 'waiting' \| 'empty' \| 'error'` | Selects hidden ready, polite loading / waiting / empty, or assertive error behavior. Any other runtime value is treated as `ready`. |
| `message?` | `string` | Overrides the built-in message for the selected kind. |

Without `message`, loading announces “Loading…”, waiting announces “Waiting for a source…”,
empty says “Nothing to show.”, error says “Something went wrong.”, and ready has no text.

**Binding**

| Member | Kind | Description |
|---|---|---|
| `snapshot()` | `() => StatusState` | Required pull port read on mount, notification, and explicit update. |
| `subscribe?(notify)` | `(notify: () => void) => () => void` | Optional publication source; its disposer runs during destruction. |

**Options**

| Member | Kind | Default | Description |
|---|---|---|---|
| `classNames` | `StatusClassNames` | `{}` | Adds compatibility classes for `root`, `indicator`, and `message`. |
| `parts` | `StatusParts` | `{}` | Adds part tokens for `root`, `indicator`, and `message`. |
| `onError` | `(error: unknown) => void` | — | Receives snapshot, subscription, and cleanup failures; errors thrown by the sink do not escape. |
| `stylesheet` | `boolean` | `true` | Installs the presenter's stylesheet unless explicitly `false`, for a light-DOM host that cannot inject CSS into its page. |

**Handle**

| Member | Kind | Description |
|---|---|---|
| `element` | `HTMLElement` | Presenter-owned `.wui-status` root. |
| `indicator` | `HTMLSpanElement` | Stable decorative `.wui-status__indicator`; visible only for loading and waiting. Its child cells are private implementation details. |
| `message` | `HTMLSpanElement` | Stable `.wui-status__message` text node. |
| `update()` | `() => void` | Re-reads State and repaints visibility, semantics, and copy. |
| `destroy()` | `() => void` | Idempotently releases the subscription and removes owned root and style nodes. Animations use CSS and allocate no timers or frame callbacks. |

**Accessibility.** Loading, waiting, and empty states use `role="status"` with polite announcements;
only loading sets `aria-busy="true"`. The indicator has `aria-hidden="true"`; loading and waiting
messages remain accessible in a visually hidden span. Error uses `role="alert"` with assertive
announcements. Ready removes live-region attributes and hides the root. The presenter never moves
focus and does not mutate unrelated caller DOM. With `prefers-reduced-motion: reduce`, or within
an ancestor using `data-motion="none"` or `data-motion="stepped"`, both indicators remain static.

</details>

<details class="component-section">
<summary>Styling</summary>

Use the shared [surface and palette tokens](/uikit/#theme-with-css-custom-properties) for
background (including `transparent`), foreground, accent, outer border and corner radius.
Presenter-specific tokens below take precedence within their documented roles.

The root uses the shared [`--wm-component-*` surface](/uikit/#theme-with-css-custom-properties),
or `--wm-status-surface-*` for a status-only override. The older status-specific box tokens below
remain compatibility fallbacks when no shared surface token overrides them.

When a stage mounts the presenter as its status overlay, it adds
`.wui-status--embedded`: that variant fills the inner viewport but removes its own background,
border, padding, and radius so the stage remains the only outer frame.

Long messages wrap within the available width, including unbroken URLs and error identifiers.
The indicators have square corners and use opacity only; loading cells share a 1.2-second cycle,
and the waiting outline uses a 2.4-second cycle. When disabling stylesheet installation, provide
equivalent indicator styling, visually hidden message treatment, and reduced-motion behavior.

**Tokens**

| Property | Falls back to | Default | Controls |
|---|---|---|---|
| `--wm-status-height` | literal | `3rem` | Minimum surface height. |
| `--wm-status-padding` | literal | `.6rem` | Internal spacing compatibility fallback. |
| `--wm-status-border` | literal | `1px solid #d8d8d8` | Normal border compatibility fallback. |
| `--wm-status-radius` | `--wm-control-radius` → literal | `0` | Corners. |
| `--wm-status-background` | `--wm-surface` → literal | `#fff` | Surface background compatibility fallback. |
| `--wm-status-foreground` | `--wm-foreground-muted` → `--wm-foreground` → literal | `#777` | Loading / waiting indicators and normal message text. |
| `--wm-status-indicator-size` | literal | `1.25rem` | Indicator width and height. |
| `--wm-status-loading-duration` | literal | `1.2s` | Loading cell opacity cycle duration. |
| `--wm-status-waiting-duration` | literal | `2.4s` | Waiting outline opacity cycle duration. |
| `--wm-status-error` | `--wm-danger` → literal | `#b42318` | Error text; error state changes the existing border to solid without replacing its color. |
| `--wm-font-family` | literal | `system-ui, sans-serif` | Message typeface. |

**Classes**

| Node | Canonical class | `classNames` key |
|---|---|---|
| Root | `.wui-status` | `root` |
| Embedded modifier | `.wui-status--embedded` | `root` |
| Indicator | `.wui-status__indicator` | `indicator` |
| Message | `.wui-status__message` | `message` |

The root also carries `data-kind="ready|loading|waiting|empty|error"` for state-aware styling.

**Parts**

| Node | Canonical part | `parts` key |
|---|---|---|
| Root | `root` | `root` |
| Indicator | `indicator` | `indicator` |
| Message | `message` | `message` |

`classNames` and `parts` append hooks beside these canonical names; they never replace them.

</details>
