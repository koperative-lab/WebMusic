The oscilloscope inspects the most recent time-domain window from a live
signal. Adjust the trigger edge and level, narrow the timebase, freeze a frame,
and probe its time and linear sample amplitude. Unlike the scrolling
[`<audio-live-view>`](/audio/element/view/audio-live-view/), it is a short-window
inspection tool, not a history or transport timeline.

## Import

```html
<script type="module">
  import {defineAudioPlayerElement} from '@webmusic/audio/play/element';
  import {defineAudioOscilloscopeElement} from '@webmusic/audio/analyze/element';
  defineAudioPlayerElement();
  defineAudioOscilloscopeElement();
</script>

<audio-player id="session" src="/mp3/Arabesque%20No.1.mp3" controls></audio-player>
<audio-oscilloscope input="#session" timebase-ms="10" trigger-edge="rising"></audio-oscilloscope>
```

The demo pairs one player with the scope. Start playback for live samples;
the tool's trigger, timebase, Freeze and pointer/keyboard probe work on its
current frame. Copy includes both Elements, and Reset restores the demo
settings.

## Ports and composition

`<audio-oscilloscope>` is an **Analyzer** module. It consumes one `audio`
output and keeps its observations in its own presentation, so it exposes no
ports of its own and provides no context to children. It resolves its input in this order:

1. `.analyser`: a caller-owned `AnalyserNode`, sampled directly.
2. `.inputModule`: a `ModuleHandle`; `null` explicitly unbinds and `undefined`
   resumes discovery.
3. `input="#id"`: one same-root element exposing `.module`, such as an
   `<audio-player>`, `<audio-mixer>` or `<audio-recorder>`. `port` names its
   audio output; the default `output` is answered by all three, and a mixer
   also answers `master`.
4. Containment: nested in an `<audio-player>` or `<audio-mixer>`, the scope
   taps the nearest provider's output.

An invalid, ambiguous or missing explicit input stays unbound and never falls
back to containment; late insertion, upgrade and replacement are observed. The
scope adds its own side tap on the port's context and never reroutes, prepares or
schedules the source: a player's port appears once it prepares on play or
preload. It registers no Session participant. Inside a provider it follows that
scope's Session; linked through `input`, it follows the linked module's
Session transport. Either way seek, pause and end reset its readings, and the
linked player's loading and load errors appear in its status.

```html
<audio-player src="/mp3/Arabesque%20No.1.mp3" controls>
  <audio-oscilloscope></audio-oscilloscope>
</audio-player>
```

## Signal and lifetime

The scope samples the analyser on its tapped input while signal flows. A
caller can assign `.analyser` for another live graph; that explicit node takes
precedence and is sampled while connected. The scope never starts playback,
creates an `AudioContext`, or retunes a borrowed node's FFT settings.

About every 50 ms it copies one `getFloatTimeDomainData()` window. Timebase is
clamped to the samples available from that analyser; a trigger chooses a
matching threshold crossing in that bounded window, or the latest available
window when no edge matches. The displayed time axis starts at the selected
window's left edge, **not** at the player's clip position. Freeze stops this
tool's polling and holds a copied frame. Inside a provider, Session pause,
seek and end, and any source replacement, clear stale readings; replacing an explicit analyser,
document hiding and graph loss also clear them. A stopped frame source reports
unavailable and is retried. Disconnect stops only this tool's poller, observers
tap and presenter, never the player or its graph.

The monochrome surface keeps Time and Amplitude in fixed readout slots and
omits a repeated title. Routine Live, Paused and Frozen messages are cleared;
No signal and No matching edge stay in the status region but are visually
hidden, and unavailable feedback remains visible. Freeze is an icon button that
uses its pressed state to indicate a held frame. The trigger edge is a group of
three square icon cells (Rising edge, Falling edge, Trigger off); the current
edge is pressed and inverted.

While waiting for an input, its prepared port or playback, the shared
outlined-square animation keeps its description accessible to assistive
technology and respects reduced motion. Input failures dispatch
`webaudio:error`. Controls and retained readings stay available.

<details class="component-section">
<summary>API</summary>

| Member | Kind | Behavior |
| --- | --- | --- |
| `input` | attribute | Same-root selector of one module element whose audio output is tapped; default absent, which uses containment. |
| `port` | attribute | Audio output name on the input module; default `output`. |
| `.inputModule` | property | `ModuleHandle` preferred over `input`; `null` unbinds and `undefined` restores selector or containment discovery. |
| `frozen` | boolean attribute | Stop this tool's polling and retain its current display; default absent. Transport/source changes release the freeze. |
| `timebase-ms` | attribute | Requested visible window in milliseconds, default `10`; invalid or non-positive values use `10`. The effective value is clamped to the analyser's sampled window. |
| `trigger-level` | attribute | Threshold in linear sample amplitude, clamped to `-1..1`; default `0`. Invalid values use `0`. |
| `trigger-edge` | attribute | `rising` (default), `falling` or `off`; other values use rising. `off` displays the latest untriggered window. |
| `aria-label` | attribute | Accessible group name; default `Oscilloscope`. |
| `.analyser` | property | Explicit caller-owned `AnalyserNode`, preferred over module input; getter exposes the current node. |
| `.frozen`, `.timebaseMs`, `.triggerLevel`, `.triggerEdge` | properties | Reflected display controls with the parsing and bounds above. |
| `.trace` | read-only property | Latest `{samples, timebaseMs, triggered, silent}` copied display window, or `undefined` without a frame. `silent` distinguishes a sampled quiet window from missing input. |
| `.selectedTimeMs` | read-only property | Probe position in milliseconds from the left edge of the displayed window. |
| `webaudio:oscilloscopeprobe` | event | `{timeMs, amplitude?}` after a pointer or keyboard probe; time is relative to the displayed window. Bubbles and is composed. |
| `webaudio:error` | event | `{error: Error}` for input, frame or presenter failures; bubbles and is composed. |

The trigger is visual alignment within sampled data, not sample-accurate
synchronization with playback or an external signal. The probe reports a
nearest displayed sample when one exists; its amplitude is omitted while the
trace is unavailable.

**Accessibility.** The canvas is a focusable slider named "Inspect waveform
time", with its selected time and amplitude in `aria-valuetext`. Arrow keys
move the probe by one percent of the visible window, Shift+Arrow by ten
percent, and Home/End select its ends. Timebase and trigger use rectangular
horizontal UIKit faders with actual-unit slider ARIA and visible values.
Arrow keys change timebase by `0.5` ms and trigger by `0.05`; Home/End select
the bounds. Timebase remains bounded by the available
samples, including windows shorter than 1 ms. The trigger-edge cells and the
Freeze button are native `aria-pressed` buttons named in `aria-label` and
`title`, and remain keyboard-operable. Probe outputs use `aria-live="off"`;
diagnostic status remains outside the canvas.

</details>

<details class="component-section">
<summary>Styling</summary>

The full-width host honors native `hidden` and uses the shared
`--wm-component-*` outer-surface tokens, with
`--wm-audio-oscilloscope-surface-*` overrides. The
[oscilloscope presenter](/uikit/views-analysis/oscilloscope/) exposes
`--wm-oscilloscope-height`, foreground, muted, border and selected-background
tokens. Its public parts are `root surface`, `header`, `readout`,
`plot`, `controls`, `freeze`, `timebase`, `trigger-level`, `trigger-edge` and
`status`. The timebase and trigger sliders also expose the shared `fader` part;
use `[part~="timebase"]` or `[part~="trigger-level"]`.
`--wm-analysis-control-height` (then `--wm-control-size`, then `2rem`) sets the
icon-button height and fader thickness, and `--wm-fader-*` styles the
horizontal controls. Canvas foreground and muted colors follow the presenter
tokens; its transparent clear preserves the configured plot background.

</details>
