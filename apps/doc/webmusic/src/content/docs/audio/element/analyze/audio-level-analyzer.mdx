The level analyzer is a live dynamics tool beside an
[`<audio-player>`](/audio/element/play/audio-player/). Its recent-sample display,
peak hold and adjustable threshold help inspect the signal while it sounds.
For offline loudness estimates over a decoded clip, use
[`measureLoudness`](/audio/api/analyze/#loudness). Neither this tool nor the
current API establishes inter-sample true peak.

## Import

```html
<script type="module">
  import {defineAudioPlayerElement} from '@webmusic/audio/play/element';
  import {defineAudioLevelAnalyzerElement} from '@webmusic/audio/analyze/element';
  defineAudioPlayerElement();
  defineAudioLevelAnalyzerElement();
</script>

<audio-player id="session" src="/mp3/Arabesque%20No.1.mp3" controls></audio-player>
<audio-level-analyzer input="#session" threshold-dbfs="-12"></audio-level-analyzer>
```

The demo pairs one player with this tool. Start playback for live samples;
the tool's Freeze, Reset and Peak threshold controls operate on its own
display.

## Ports and composition

`<audio-level-analyzer>` is an **Analyzer** module. It consumes one `audio`
output and keeps its observations in its own presentation, so it exposes no
ports of its own and provides no context to children. It resolves its input in this order:

1. `.analyser`: a caller-owned `AnalyserNode`, sampled directly.
2. `.inputModule`: a `ModuleHandle`; `null` explicitly unbinds and `undefined`
   resumes discovery.
3. `input="#id"`: one same-root element exposing `.module`, such as an
   `<audio-player>`, `<audio-mixer>` or `<audio-recorder>`. `port` names its
   audio output; the default `output` is answered by all three, and a mixer
   also answers `master`.
4. Containment: nested in an `<audio-player>` or `<audio-mixer>`, the tool
   taps the nearest provider's output.

An invalid, ambiguous or missing explicit input stays unbound and never falls
back to containment; late insertion, upgrade and replacement are observed. The
tool adds its own side tap on the port's context and never reroutes, prepares or
schedules the source: a player's port appears once it prepares on play or
preload. It registers no Session participant. Inside a provider it follows that
scope's Session; linked through `input`, it follows the linked module's
Session transport. Either way seek, pause and end reset its readings, and the
linked player's loading and load errors appear in its status.

```html
<audio-player src="/mp3/Arabesque%20No.1.mp3" controls>
  <audio-level-analyzer></audio-level-analyzer>
</audio-player>
```

## Signal and lifetime

The element samples the analyser on its tapped input while signal flows.
Assign `.analyser` to inspect a caller-owned graph instead; an explicit
analyser takes precedence and is sampled while the element remains connected.
The element does not create an `AudioContext`, decode a clip, seek, or own a
borrowed node. It samples about every 50 ms, so the RMS and peak
describe sampled windows, not continuous loudness or inter-sample true peak.
The crest value is sample peak minus RMS in dB.

Freeze holds the current display while sampling continues. Reset starts
the held peak again from the current sample. A pause, seek, source change or
missing live input clears stale samples; a frame stall marks the signal
unavailable. The element stops its own polling, tap and subscriptions on
rebind or disconnect without stopping the player.

RMS, Peak hold and Crest stay in fixed positions above the history. The
monochrome surface omits a repeated title and routine Live, Paused or Frozen
messages. No signal stays in the status region but is visually hidden;
unavailable feedback remains visible. Freeze and Reset hold
are icon buttons in one non-wrapping row with the threshold fader.

While waiting for an input, its prepared port or playback, the shared
outlined-square animation keeps its description accessible to assistive
technology and respects reduced motion. Input failures dispatch
`webaudio:error`. Controls and retained readings stay available.

<details class="component-section">
<summary>API</summary>

| Member | Kind | Behavior |
| --- | --- | --- |
| `input` | attribute | Same-root selector of one module element whose audio output is tapped; default absent, which uses containment. |
| `port` | attribute | Audio output name on the input module; default `output`. |
| `.inputModule` | property | `ModuleHandle` preferred over `input`; `null` unbinds and `undefined` restores selector or containment discovery. |
| `threshold-dbfs` | attribute | Sample-peak comparison threshold in dBFS, clamped to `-60..0`; default `-12`. Invalid values use `-12`. |
| `.analyser` | property | Caller-owned `AnalyserNode`; takes precedence over module input. |
| `.thresholdDbfs` | property | Reflected peak threshold in dBFS. |
| `.sample` | read-only property | Latest `{rmsDbfs, peakDbfs}` sample, or `undefined` without a live sample. |
| `.heldPeakDbfs` | read-only property | Greatest sampled peak since the latest reset, or `undefined` before a sample. |
| `.frozen` | read-only property | Whether the display is frozen; the tool's Freeze control changes it. |
| `webaudio:levelchange` | event | `{rmsDbfs, peakDbfs, crestDb, heldPeakDbfs, thresholdDbfs}` for an accepted sample; bubbles and is composed. |
| `webaudio:error` | event | `{error: Error}` for a live-input or frame failure; bubbles and is composed. |

The threshold is visual feedback against the sampled peak; crossing it does
not mute, compress or otherwise change the signal.

**Accessibility.** Freeze is an icon button named in `aria-label` and `title`
that exposes `aria-pressed`; the Reset icon button has the accessible name
"Reset hold". The horizontal UIKit threshold fader has
a visible dBFS value and a labelled slider role with `-60..0` bounds. Arrow
keys change it by 1 dB, and Home/End select the bounds. Numeric
readings and diagnostic status remain available outside the history plot.

</details>

<details class="component-section">
<summary>Styling</summary>

The full-width host honors native `hidden`. Its outer surface uses
`--wm-component-background`, `--wm-component-border`,
`--wm-component-padding` and `--wm-component-radius`; the
`--wm-audio-level-analyzer-surface-*` tokens override this tag. The
[level presenter](/uikit/views-analysis/level-analyzer/) exposes `--wm-level-analyzer-rms`,
`--wm-level-analyzer-peak` and `--wm-level-analyzer-threshold` for its graph.
The default colors are gray and ink. `--wm-analysis-control-height` (then `--wm-control-size`, then `2rem`) sets the
icon-button height and fader thickness; `--wm-fader-*` styles the horizontal threshold
fader. Public parts are `root surface`, `freeze`, `reset` and `threshold`; the
slider also has `fader`, so use `[part~="threshold"]`.

</details>
