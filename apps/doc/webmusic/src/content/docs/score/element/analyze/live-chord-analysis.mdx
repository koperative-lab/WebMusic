This component displays only the current chord name and optional alternate interpretations. Choosing an alternate updates this nameplate until the sounding set changes. Applications that need past transitions can retain timestamped [Headless tracker updates](/score/headless/analyze/live-trackers/#chord-history).

<AnalysisFeaturePlayground tag="live-chord-analysis" />

The demo uses an original four-bar C–F–G–C exercise in 4/4 at 100 bpm, with simultaneous whole-note triads for the nameplate to identify.

## Import

```html
<script type="module">
  import {defineScorePlayerElement} from '@webmusic/score/play/element';
  import {defineLiveChordAnalysisElement} from '@webmusic/score/analyze/element';
  defineScorePlayerElement();
  defineLiveChordAnalysisElement();
</script>

<score-player id="piece" src="/xml/chord-progression.musicxml"></score-player>
<live-chord-analysis player="#piece"></live-chord-analysis>
```

The live demo pairs this component with one `<score-player>`. Parameters configures those two elements; Copy includes their markup and Reset restores their original attributes and connection. For optional supporting views, see [Compose a performance](/score/element/#compose-a-performance). `defineLiveChordAnalysisElement(tag?)` is idempotent and SSR-safe; `defineAllAnalysisElements()` registers the Analyze family from the same entry.

## Behavior and lifetime

Alternate readings are the component’s musical interaction. Display configuration stays in the external Parameters section. The component has no history lane, score seek, keyboard, staff, fretboard, tabs or settings strip.

This tag uses the selected player’s held notes and note/state events. When available, the player’s `.playback` [shared source](/score/api/#shared-playback-observation) supplies current activity and subsequent updates; the event path remains a compatibility fallback. It has no score-loading attributes. A native snapshot initializes current held notes, while a structural event-only source begins with incoming notes. Without note input it waits. Late or replaced targets are rebound.

The selector must match exactly one target in the current Document or ShadowRoot. Invalid or ambiguous matches remain unbound. Native single-score player mode supplies complete initial data/state; Rack/controller modes do not promise that snapshot. Disconnect cancels owned work, releases subscriptions/observation and destroys presenters, while the borrowed player keeps its own lifetime.

<details class="component-section">
<summary>API</summary>

### Attributes

| Attribute | Values / default | Behavior |
| --- | --- | --- |
| `player` | selector, absent | Exactly one source in the component’s Document or ShadowRoot; borrow held notes, state and note events. |
| `density` | `comfortable` / `compact`, `comfortable` | Type and spacing defaults for this surface. |
| `scheme` | `light` / `dark`, inherited | Pin this surface’s palette; removing it follows the page. |
| `spelling` | `auto` / `sharp` / `flat`, `auto` | Pitch-name spelling from the available key context or an explicit preference. |
| `alternates` | `show` / `hide`, `show` | Include or omit alternate chord readings on the nameplate. |

Unknown display values fall back to the documented default. This fixed component has no `type`, `show`, `shell`, `range` or `tuning` control; configure sibling pitch views on their own tags.

### Properties

| Property | Type | Behavior |
| --- | --- | --- |
| `.density` | `comfortable \| compact` | Reflected density. |
| `.scheme` | `light \| dark \| undefined` | Reflected palette; undefined removes the override. |
| `.spelling` | `auto \| sharp \| flat` | Reflected pitch spelling. |
| `.chord` | read-only `string \| undefined` | Displayed chord symbol; undefined for silence. |

`LiveChordAnalysisElement` is exported from `@webmusic/score/analyze/element`. There are no public playback methods.

### Events

All emitted events bubble and are composed.

| Event | Detail | Trigger |
| --- | --- | --- |
| `webscore:chordchange` | `{chord, midis}` | The detected chord changes to a nonempty name. Silence and reset clear the display without emitting this event. |
| `webscore:chordpick` | `{symbol, kind, midis}` | A nameplate alternate is chosen. |

### Accessibility

The nameplate exposes the current name and pitches as text. Alternate readings are named keyboard-operable buttons. It has no slider or transport command. Automatic motion respects reduced-motion preference on moving surfaces; display controls remain outside the component.

<details class="component-section">
<summary>Styling</summary>

The component uses light DOM. Its block host fills the available width and can shrink in flex/grid layouts; application CSS can override its layout. Set public tokens on this host or any ancestor. The component does not install host-local theme defaults that mask inherited values.

One outer surface owns background, border, padding and radius. The inner musical presenter stays unframed, so translucent backgrounds are painted once. Use `--wm-component-background`, `--wm-component-border` (a complete CSS border), `--wm-component-radius` and `--wm-component-padding`; the corresponding `--wm-workbench-surface-*` tokens provide a specific override. Without overrides this Analyze surface remains transparent, borderless and unpadded. `--wm-surface`, `--wm-foreground`, `--wm-accent`, `--wm-border` (a color) and `--wm-control-radius` supply shared palette and control defaults. Existing `--wm-analysis-*` and `--wm-harmony-*` palette overrides remain supported.

```css
live-chord-analysis {
  --wm-component-background: transparent;
  --wm-component-border: 1px solid #94a3b8;
  --wm-component-radius: .75rem;
  --wm-foreground: #0f172a;
  --wm-accent: #7c3aed;
  --wm-accent-foreground: #fff;
}
```

Nameplate text follows `--wm-foreground`; `--wm-harmony-foreground` can override only this presenter family. Alternate-name controls use `--wm-accent` and `--wm-accent-foreground`; the latter is independent of the surface background.

Stable part tokens are `root` on the direct child wrapper, `presentation`, `surface`, `content`, `index`, and `nameplate` and `symbol`. Use selectors such as `live-chord-analysis [part~="surface"]` in application CSS. These are light-DOM hooks, not Shadow DOM `::part()` selectors; private `.wui-*` classes are not an API. The same hooks remain available after configuration changes and reconnects.

The [harmony presenter](/uikit/views-analysis/harmony/) and [workbench presenter](/uikit/layout-feedback/workbench/) own the complete token references. No header, tabs, dock controls or sibling pitch views are embedded in this component.

</details>
