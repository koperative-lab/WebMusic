## Import

```html
<script type="module">
  import {defineScorePlayerElement} from '@webmusic/score/play/element';
  import {defineScaleAnalysisElement} from '@webmusic/score/analyze/element';
  defineScorePlayerElement();
  defineScaleAnalysisElement();
</script>

<score-player id="piece" src="/mxl/Arabesque%20No.1.mxl"></score-player>
<score-scale-analysis player="#piece" window="1" tonic="E" scale="major"></score-scale-analysis>
```

Registration is idempotent and SSR-safe. `defineAllAnalysisElements()` registers all four tools from the same entry; see the [family inventory](/score/element/#analyze). This demo contains one player and one inspection surface. Its one-second initial window keeps the dense opening notes readable; adjust `window` to inspect a longer passage. External Parameters configures them; Copy includes their actual markup and Reset restores attributes and the player connection. Optional sibling views belong in [an application composition](/score/element/#compose-a-performance).

## Musical reading

The tonic is required and explicitly spelled, such as C, F♯ or B♭. Without it the surface asks for a tonic rather than guessing from the score. Major, natural minor, harmonic minor, ascending melodic minor and descending melodic minor are separate reference forms. Melodic-minor direction is a chosen reference, not an inference from the melody's last motion. Ascending melodic minor raises degrees 6 and 7; descending melodic minor uses the natural-minor form.

A note's letter establishes the degree and its accidental establishes alteration against the chosen scale spelling. In C major F♯ is ♯4 while G♭ is ♭5; enharmonic equality does not erase that distinction. In-scale membership requires exact reference spelling. `pitch-mode="sounding"` applies declared part transposition and retains written-pitch provenance; inferred transposition spelling is identified in the evidence. It does not change the Score.

The demo loads the existing [Arabesque No. 1 MXL](/mxl/Arabesque%20No.1.mxl) and explicitly chooses E major as its starting reference, matching the source title and opening four-sharp signature. This choice remains fixed while inspecting the piece; it is not a detected key or a claim that every later passage belongs to E major. Clear the tonic to see the required-input state, or choose another tonic/scale form to compare the same actual notes against that reference.

`spellingInferred` in underlying note evidence marks spelling inferred during analysis-time transposition only. It does not detect spelling chosen earlier by an importer; a false flag cannot establish authored spelling for a MIDI-origin Score.

The current readout shows the degree above three fixed, equal-width fields: **Note**, **Reference** and **Relation**. The reference names the explicitly chosen tonic and scale form; relation describes membership or alteration. Field labels and positions stay fixed while playback updates their values, and long values wrap inside their own field. Space is reserved from all supplied readings when content or geometry changes; gaps clear the values while retaining labels and slots. Quieter context identifies the pitch basis. Lane rows still compact to the visible material without changing the reference or source evidence.

## Binding and lifetime

Explicit `.score` wins over `src`, then the selected player's resolved Score. Native bindings prefer the player's `.playback` [shared source](/score/api/#shared-playback-observation), including its initial readiness, data, position and note identities. Late, upgraded or replaced targets are rebound. Invalid or ambiguous selectors stay unbound. Targets without an available native source retain the compatibility snapshot/event path; they do not promise an initial snapshot.

Failed explicit loading does not fall back to unrelated player data; empty input and errors are shown by the surface. Superseded loads cannot restore old input. An explicit Score different from the native player's Score suppresses mismatched activity and cannot seek that owner. Pointer selection and keyboard navigation use `seekNominal()` when available, otherwise convert nominal seconds by the current rate before `seek()`. Failed commands restore the previous local position unless newer state has arrived. Standalone navigation still emits a seek request.

The component owns its URL request, analysis projection, target observer, subscriptions and presenters. Disconnect cancels/releases those resources. The player retains its lifetime, Score, sound and authoritative timeline. No Analyze component creates a player, synth, AudioContext or playback scheduler.

### Properties and methods

| Property | Type | Behavior |
| --- | --- | --- |
| `.score` | `Score \| undefined` | Explicit input; clearing resumes `src`, then borrowed player data. |
| `.selection` | read-only `AnalysisSelection \| undefined` | Local selected band/passage: `id`, `startQuarters`, `endQuarters`. |
| `.analysis` | read-only `AnalysisInspection \| undefined` | Selected `kind`, `selection`, `headline`, `detail`, `evidence` and `candidates`; full provenance remains available beyond the compact lane readout. |
| `.density` | `comfortable \| compact` | Reflected density. |
| `.scheme` | `light \| dark \| undefined` | Reflected palette; undefined removes the override. |
| `.motion` | `auto \| continuous \| stepped \| none` | Reflected motion policy. |
| `.window` | `number \| auto` | Reflected visible duration in seconds. |
| `.tonic` | `string \| undefined` | Reflected explicit tonic; undefined removes it. |
| `.scale` | `TheoryScale` | Reflected scale form. |
| `.pitchMode` | `written \| sounding` | Reflected pitch basis. |

`ScaleAnalysisElement`, `AnalysisSelection`, `AnalysisInspection`, `AnalysisSeekDetail` and `AnalysisSelectDetail` are exported from `@webmusic/score/analyze/element`.

`selectRegion(startQuarters, endQuarters)` selects a finite increasing quarter-note passage without seeking. It clamps to the loaded Score, throws `RangeError` for invalid/wholly out-of-score bounds, and has no effect without a Score. `clearSelection()` returns to the first available band. Neither method edits notes or commands playback. `selectNotes(noteIds: readonly string[])` restricts the inspection to exact source note IDs without seeking; an empty array restores attribute filtering. Empty/non-string IDs throw `TypeError`. Selection retains the `part`/`voice` filters. Unknown IDs provide no matching evidence.

### Events and accessibility

All emitted events bubble and are composed.

| Event | Detail | Trigger |
| --- | --- | --- |
| `webscore:seek` | `AnalysisSeekDetail`: `{quarters, seconds}` | Lane navigation; quarter notes and nominal score seconds. |
| `webscore:analysisselect` | `AnalysisSelectDetail`: `{kind: 'scale', id, startQuarters, endQuarters}` | Band/region selection; local inspection state. |

The score lane is a named slider tab stop. Arrow keys, Home/End and `[` / `]` navigate; pointer selection chooses a band and seeks. A semantic ordered list marks the current span with `aria-current`; detailed selection evidence has a nonvisual status. Passive playback does not repeatedly announce a local selection. Display configuration remains outside the component, and automatic motion respects reduced-motion preference.
